# Прогноз цен на квартиры в Москве

Учебный проект машинного обучения: построить и оценить модель, которая прогнозирует цену квартиры по её характеристикам.

## Постановка задачи

Это задача **регрессии**. Для каждой квартиры известны характеристики, а модель должна предсказать числовое значение — цену из столбца `real_price`.

**Цель проекта:** пройти полный цикл работы с табличными данными — от проверки исходного CSV до сравнения моделей, оценки ошибок и прогноза для новой квартиры.

**Целевая переменная:** `real_price` — цена в рублях, как она указана в наборе данных.

**Признаки:** число комнат, площадь, состояние ремонта, этаж и этажность дома. Дополнительно создаются признаки положения квартиры в доме и площади на комнату.

## Данные

Файл `main_data.csv` содержит 4 000 записей по пяти городам. Для проекта используются 800 записей с `city == "Moscow"`.

| Столбец | Значение |
| --- | --- |
| `city` | Город |
| `rooms` | Число комнат |
| `m2` | Общая площадь, м² |
| `repair` | Категория состояния ремонта |
| `floor` | Этаж квартиры |
| `all_floor` | Этажность дома |
| `real_price` | Цена в рублях; целевая переменная |

Набор опубликован на [Hugging Face](https://huggingface.co/datasets/zect7/Russian_apartment_price). В описании набора `real_price` назван фактической ценой, однако независимая проверка происхождения и смысла этих значений в рамках проекта не проводилась. Перед практическим применением это нужно уточнить.

## План решения

1. Загрузить CSV и проверить его размер, столбцы и распределение записей по городам.
2. Оставить московские квартиры.
3. Проверить типы данных, пропуски, дубликаты и базовую логическую корректность значений.
4. Изучить распределения цен, связь цены с площадью и медианную цену по категории ремонта.
5. Создать дополнительные признаки: отношение этажа к этажности, первый/последний этаж, площадь на комнату и признак высотного дома.
6. Разделить данные на обучающую и тестовую части. Тест используется только для итоговой оценки.
7. Собрать конвейер подготовки данных: заполнение пропусков, масштабирование числовых признаков и one-hot кодирование `repair`.
8. Сравнить медианный ориентир, Ridge-регрессию и случайный лес с помощью кросс-валидации.
9. Настроить параметры случайного леса на обучающей части.
10. Оценить выбранную модель на тестовой части, изучить отдельные ошибки и важность признаков.
11. Сделать прогноз для новой квартиры и сохранить обученный конвейер.

## Метрики

- **MAE** — средняя абсолютная ошибка в рублях. Удобна для ответа на вопрос: «На сколько рублей модель ошибается в среднем?»
- **RMSE** — квадратный корень из средней квадратичной ошибки. Сильнее реагирует на отдельные крупные промахи.
- **R²** — дополнительная метрика соответствия прогнозов разбросу цен; чем ближе к 1, тем лучше. Отрицательное значение означает, что модель хуже простого прогноза средним.
- **Процент ошибки по объекту** — абсолютная ошибка конкретной квартиры относительно её фактической цены.

В ноутбуке модель сравнивается с медианным ориентиром. Это помогает проверить, действительно ли машинное обучение даёт выигрыш относительно простого прогноза.

## Запуск

1. Открой `Прогноз_цен.ipynb` в Google Colab или Jupyter.
2. Убедись, что `main_data.csv` доступен из рабочей папки ноутбука. В Colab файл нужно загрузить в среду выполнения или разместить на подключённом Google Диске.
3. Запускай ячейки сверху вниз.
4. В конце изучи тестовую таблицу метрик, график фактических цен и прогнозов, таблицу крупнейших ошибок и итоговую ячейку.

В ноутбуке используются Python, pandas, NumPy, Matplotlib и scikit-learn. Модель сохраняется в файл `moscow_apartment_price_model.joblib` в текущую рабочую папку.

## Текущие наблюдения

- В московской выборке 800 записей до дополнительной проверки качества данных.
- Корреляция площади и цены в исследованной выборке составляет примерно **0,756**. Это заметная положительная связь, но площадь не объясняет всю разницу в цене.
- На присланном графике фактических цен и прогнозов точки в целом следуют диагональному направлению, но есть крупные отклонения.
- Среди крупнейших показанных ошибок модель завысила цену примерно на **15,7 млн ₽** для квартиры с фактической ценой 32,6 млн ₽ и на **13,3 млн ₽** для квартиры с фактической ценой 18,7 млн ₽.

Итоговые MAE, RMSE и R² зависят от выполненного запуска и должны быть взяты из таблицы `test_results` в ноутбуке. В этот README они не внесены, поскольку сами значения этой таблицы пока не были предоставлены.

## Ограничения

- Выборка небольшая: около 800 квартир Москвы.
- В данных отсутствуют район, адрес, расстояние до метро и центра, год постройки, тип дома и другие важные характеристики.
- По названию и краткому описанию источника нельзя независимо подтвердить, отражает ли `real_price` фактические сделки, цену объявления или иной показатель.
- Большая ошибка на отдельном объекте показывает, что средняя метрика не гарантирует точности для конкретной квартиры.

Поэтому проект предназначен для обучения и анализа этого набора данных. Его результаты нельзя считать проверенной оценкой рыночной стоимости квартир.
